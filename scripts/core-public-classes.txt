# Public core classes: the classes from the core stylesheets (admin/css/)
# that a plugin's own screens, tabs and feature output may use, so they look
# like the settings screen. One class per line; # starts a comment.
# STYLING.md → Classes a plugin may use explains them.
#
# Use them in markup freely; never restyle them (no plugin CSS rule whose
# selector ends on one). A plugin's own components take their own names:
# spcc-<screen>-* or spcc-app-*. Every other class in the core stylesheets is
# internal: a starter sync may change or remove it without notice.
# Changing or removing a class here is a changelog item that plugins must act
# on. scripts/preflight-release.sh (Core class names) reads this file.
